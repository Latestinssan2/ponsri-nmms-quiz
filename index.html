FOR CHATGPT / GEMINI / CLAUDE

AI ક્વિઝ જનરેટર પ્રોમ્પ્ટ

આ પ્રોમ્પ્ટ કોપી કરી AI ને આપો. AI આપમેળે આ પોર્ટલ માટે યોગ્ય JSON બનાવી આપશે!

તમે એક કુશળ શિક્ષક અને પરીક્ષા પ્રશ્નપત્ર નિર્માતા છો.
નીચે આપેલા પ્રશ્નો અથવા પ્રશ્નપત્રના લખાણને NMMS / શિષ્યવૃત્તિ પરીક્ષા માટે યોગ્ય એવા ચોક્કસ JSON ફોર્મેટમાં રૂપાંતરિત કરો.

નિયમો:
1. દરેક પ્રશ્નમાં 4 વિકલ્પો (A, B, C, D) હોવા જોઈએ.
2. "answer" માં સાચા વિકલ્પનો 0-based ઇન્ડેક્સ આપો (A માટે 0, B માટે 1, C માટે 2, D માટે 3).
3. દરેક પ્રશ્નની ટૂંકી ગણતરી કે સમજૂતી "explanation" માં આપો.
4. ભાષા ગુજરાતી હોવી જોઈએ.
5. માત્ર વેલિડ JSON જ આઉટપુટ આપો, આગળ કે પાછળ કોઈ વધારાનું લખાણ ન આપો.

JSON ફોર્મેટ નીચે મુજબ હોવું જોઈએ:
{
  "title": "NMMS પરીક્ષા SAT મોક કસોટી",
  "durationMinutes": 60,
  "school": "PM SHRI PRATHMIK VIDHYAMANDIR PONSRI",
  "questions": [
    {
      "id": 1,
      "question": "પ્રશ્ન અહીં લખો...",
      "options": ["વિકલ્પ A", "વિકલ્પ B", "વિકલ્પ C", "વિકલ્પ D"],
      "answer": 0,
      "explanation": "સાચા જવાબની વિગતવાર સમજૂતી..."
    }
  ]
}

અહીં પ્રશ્નો આપેલા છે:
[અહીં તમારા પ્રશ્નો અથવા પ્રશ્નપત્રનો ફોટો/લખાણ પેસ્ટ કરો]

સરળ પદ્ધતિ:

1. ઉપરનું "પ્રોમ્પ્ટ કોપી કરો" બટન દબાવો.

2. ChatGPT અથવા Google Gemini ખોલી પ્રોમ્પ્ટ પેસ્ટ કરો અને નીચે તમારા પ્રશ્નો કે ફોટો જોડો.

3. AI જે JSON કોડ આપે તે કોપી કરી બાજુના "JSON ક્વિઝ ઈમ્પોર્ટ" ટેબમાં પેસ્ટ કરો અને પબ્લિશ કરો!
